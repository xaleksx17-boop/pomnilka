# Помнилка — голосовой дневник ухода

*Создано для любимого котёнка* 🐾  
Автор: Кузнецов Александр Алексеевич

Говоришь «полил красулю» — приложение записывает, ставит следующий раз в календарь и напоминает.
Наводишь камеру на растение — узнаёт его и говорит, когда поливать.

## Сборка APK
1. Android Studio (Ladybug 2024.2 или новее) → **Open** → папка `Pomnilka`.
2. Дождаться синхронизации Gradle (скачает AGP 8.7, Vosk, MediaPipe).
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
   Release-вариант подписан отладочным ключом — ставится на свой телефон без возни.
4. Скопировать APK на телефон и установить (разрешить установку из неизвестных источников).

Из консоли: `gradlew assembleDebug` (тесты разбора фраз: `gradlew test`).

## Первый запуск
- Разрешить уведомления.
- **Настройки → Vosk «Скачать (~45 МБ)»** — офлайн-распознавание речи. Без него работает Google (нужен интернет).
- **Настройки → Распознавание по фото «Скачать (~4 МБ)»** — нейросеть MobileNet. Без неё узнаёт по цвету/форме, хуже.
  Если с телефона не скачивается — скачать файлы на ПК и выбрать «Из zip» / «Из файла»:
  - https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
  - https://storage.googleapis.com/mediapipe-models/image_embedder/mobilenet_v3_small/float32/1/mobilenet_v3_small.tflite
- **Календарь**: включить «Дублировать в календарь», выбрать календарь или создать локальный «Помнилка».
- Долгое нажатие на значок приложения → ярлыки «Сказать» и «Узнать по фото» (можно вынести на рабочий стол).

## Что понимает голосом
| Фраза | Что происходит |
|---|---|
| «полил красулю» | отметка + следующий раз по интервалу из справочника |
| «вчера полила фикус» | отметка вчерашним днём |
| «полил красулю, следующий через 10 дней» | только ближайший раз через 10 дней |
| «подкормил фикус каждые две недели» / «раз в месяц» | меняет интервал в справочнике |
| «когда поливать красулю?» | отвечает голосом |
| «что сегодня?» | перечисляет, что пора сделать |
| «отмена» | отменяет последнюю отметку |
| неизвестный предмет | предложит новую запись (можно сразу с фото) |

Если голосовая форма слова не узнаётся — допиши её в поле «Другие слова» записи (например «толстянка, поливал»).

## Распознавание по фото
У каждой записи — фото. Кнопка с камерой на главном экране: снимок сравнивается со справочником,
приложение говорит «Полить красулю — через 3 дня, 20 октября». Кнопка «Сделано» отмечает полив.
Каждое подтверждение запоминается как ещё один эталонный снимок (до 6 на запись) — со временем узнаёт увереннее.
Если узнало не то — «Не то» → выбрать вручную; снимок тоже запомнится.

## Устройство
- `CommandParser.kt` — разбор русских фраз (чистый Kotlin, покрыт тестами).
- `Db.kt` — SQLite: справочник и история.
- `Reminders.kt`, `AlarmReceiver.kt` — будильники, уведомления с кнопками «Сделано»/«Завтра», перезапуск после перезагрузки.
  Если не сделано — напоминает каждый день, пока не отметишь.
- `CalendarSync.kt` — события в системном календаре (запланированное + отметка «✓»).
- `VoskEngine.kt` — офлайн-речь, `Speaker.kt` — голосовые ответы.
- `PhotoMatcher.kt`, `Photos.kt` — фото и распознавание.

Минимальная версия Android — 8.0.
